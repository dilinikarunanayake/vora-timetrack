# Images

## Image slots: add your own files here

Save a file with exactly this name (any of .svg, .png, .webp, .jpg) and it appears
automatically. Remove it and the page falls back to the built-in illustration or text.
No code changes needed; just refresh the page.

| File (without extension)                  | Where it shows                     | Best size / notes                                   |
|-------------------------------------------|------------------------------------|-----------------------------------------------------|
| `brand/vora-global-solutions-logo`        | Home page and sign-in page         | Provided. Transparent PNG, designed for dark backgrounds |
| `brand/vora-nexus-logo`                   | Home page "two businesses" section | Transparent PNG or SVG, at least 600 px wide, for a dark background |
| `photos/team`                             | Home page, wide band near the end  | Landscape photo, 1600 × 700 px or larger, JPG       |
| `photos/sign-in`                          | Sign-in page, replaces the illustration | Portrait or square photo, 1000 × 1200 px, JPG  |

Only use photos you have permission to publish (ask your team before using their faces).

## Built-in illustrations

`illustrations/` holds original SVG drawings made for Vora TimeTrack, in the brand colours:
`workflow-diagram.svg` (home page), `engineer-workstation.svg` (sign-in),
`role-*.svg` (home page role previews) and `all-caught-up.svg` (empty approvals queue).
`brand/timetrack-mark.svg` is the app icon used in the menu bar and browser tab.
